Getting started

From zero to your own cloud in 5 minutes.

1

Get a server

Any Linux VPS with a public IP. We recommend Hetzner ($5/mo) — add a volume for persistent storage so your data survives if you rebuild the server.

2

Point your domain

Create a DNS A record pointing your domain to the server IP. Example: cloud.example.com → 1.2.3.4

3

Run the installer

SSH into your server and run:

curl -fsSL https://kiedanski.github.io/tilde/install.sh | bash copied!

The installer downloads the binary, sets up TLS certificates (Let's Encrypt), creates a systemd service, and gives you an app password. If you have a backup on Backblaze B2, it can restore from there automatically.

4

Connect your devices

iPhone/Mac: Open https://cloud.example.com/apple-mobileconfig in Safari — auto-configures Calendar & Contacts.

Android: Install DAVx5 for calendar/contacts sync. Install WebGallery for photo browsing and auto-upload from your camera roll.

Desktop: Mount files via rclone or any Nextcloud client. Notes work with any WebDAV-capable editor.

5

Upload your photos

Drop photos into /dav/photos/_inbox/ via any WebDAV client, rclone, or the WebGallery app. Tilde reads EXIF dates, organizes into year/month/ folders, and generates thumbnails automatically.

One command. Works on any Linux server with a domain.

1. Get a server

# Any VPS works. Recommended: Hetzner CX23
# ~$5/mo for 4 GB RAM, 40 GB disk
# Add a volume for persistent data

2. Point your domain

# Create a DNS A record:
cloud.example.com  →  YOUR_SERVER_IP

3. Run the installer

curl -fsSL \
  https://kiedanski.github.io/tilde/install.sh \
  | bash

4. Connect your devices

# iOS: open in Safari
https://cloud.example.com/apple-mobileconfig

# Android: DAVx5 with base URL
# Files: any Nextcloud or WebDAV client

Configuration

Everything in one TOML file at /etc/tilde/config.toml

Server & TLS

[server]
hostname = "cloud.example.com"
listen_addr = "0.0.0.0"
listen_port = 443

[tls]
mode = "acme"   # automatic Let's Encrypt

Photos

[photos]
enabled = true
organization_pattern = "{year}/{month:02}"
thumbnail_sizes = [256]
thumbnail_quality = 80

Backups

[backup]
enabled = true
schedule = "daily@04:00"

[[backup.offsite]]
name = "b2"
type = "s3"
endpoint = "https://s3.us-east-005.backblazeb2.com"
bucket_env = "TILDE_BACKUP_B2_BUCKET"
key_id_env = "TILDE_BACKUP_B2_KEY_ID"
key_env = "TILDE_BACKUP_B2_KEY"

Email Archive

[email]
enabled = true

[[email.accounts]]
name = "personal"
imap_host = "imap.example.com"
imap_port = 993
username_env = "TILDE_EMAIL_USERNAME"
password_env = "TILDE_EMAIL_PASSWORD"

Notifications

# In /etc/tilde/.env:
TILDE_NTFY_TOPIC=https://ntfy.sh/my-topic

# Sends push notifications on:
# - Server start/restart
# - Backup failures
# - Disk usage > 80%

Migrating from...

Bring your data. No lock-in.

From Google Photos

# 1. Google Takeout → download photos.zip
# 2. Upload to tilde:
rclone copy ~/Downloads/photos/ \
  tilde:/photos/_inbox/
# tilde auto-organizes by EXIF date

From Nextcloud

# Files: copy data dir
cp -r /nextcloud/data/admin/files/* \
  /data/tilde/files/

# Calendar/Contacts: export + import
# via CalDAV/CardDAV clients

From iCloud

# Calendar: already synced via CalDAV
# Contacts: already synced via CardDAV
# Photos: upload via WebDAV or rclone
# Notes: copy .md files to /dav/notes/

From another tilde

# Just restore from backup:
curl -fsSL .../install.sh | bash
# Choose "Restore from Backblaze B2"
# Enter your B2 credentials
# Done — all data migrated
